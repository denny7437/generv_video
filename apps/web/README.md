# apps/web — фронтенд

**Пусто. Это первая задача фазы E1–E3, а не забытый каталог.**

Каталог оставлен намеренно: `hermes-lead` при декомпозиции должен видеть, что модуль запланирован, но не существует, и не делегировать в него задачи до создания.

## Что должно появиться

Кабинет селлера: загрузка карточки товара и медиа, форма брифа, статус генерации, превью и выдача готового ролика.

## Обязательная нулевая фаза

Задача на создание этого модуля начинается с разведки open source (скилл `hermes-oss-scout`), а не с `create-next-app`. Направления для поиска — `hermes-video-pipeline/references/oss-landscape.md`, раздел «Фронтенд»: база, плеер и превью, редактор таймлайна, загрузка файлов. В этой нише много заброшенных репозиториев — живость проверяется по дате последнего коммита, а не по звёздам.

Решение по стеку — долгоживущее, поэтому оформляется ADR (`hermes-architect`), а не выбирается исполнителем в одиночку.

## Границы

- Фронтенд не знает о провайдерах генерации: он работает только с `contracts/openapi/api.yaml`.
- Параметры выдачи (9:16, длительность, вес) приходят из пресета, в вёрстку не зашиваются.
