# MarketGuru — верификация фото и API (закрывает ли playbook и golden set) — 2026-08-18

Дополнение к TEC-36 «Выбор сервиса аналитики маркетплейсов». Задача **TEC-37**.
Назначение: проверить, закрывает ли MarketGuru потребность источника данных для
playbook (TEC-28) и golden set (TEC-31) на приоритетной площадке **Ozon**
(`configs/mvp_scope.yaml → platform_priority.first = ozon`).

## Резюме

**MarketGuru НЕ закрывает задачу источника данных для playbook и golden set на Ozon.**
Три причины, каждая подтверждена первоисточником:

1. **Ozon-аналитика ниш/топ-карточек отсутствует.** Разделы «Поиск ниши»,
   «Что продавать», «Категории», «Анализ по артикулу» — только Wildberries.
   Ozon в MarketGuru покрыт лишь работой со СВОИМ магазином (Биддер Ozon,
   Автоответы Ozon, Performance API Ozon для рекламы).
2. **Публичного API нет.** Нет ни `api.marketguru.io`, ни документации API для
   клиентов; все упоминания «API» — это подключение ключей продавца WB/Ozon
   внутрь сервиса. Единственная исходящая интеграция — кастомная, в тарифе
   «Индивидуальный холдинг», через форму «Оставить заявку», без прайса.
3. **Фото карточек — только просмотр в UI и только WB.** В «Анализ по артикулу»
   фото товара открываются на просмотр; выгрузка фото не документирована.
   Документированы только «скачать отзывы», «скачать вопросы» и Excel-выгрузка
   таблиц (WB).

Рекомендация — **MPStats** (публичный REST API `https://mpstats.io/api/` + покрытие
Ozon). Дороже (от 10 392 ₽/мес, со слов TEC-36/TEC-37), но это единственный из двух
кандидатов с публично подтверждённым API и Ozon. Решение и оплата — за Денисом.

## Что это значит для продукта

1. **Источник для playbook (TEC-28) и golden set (TEC-31) на Ozon нельзя строить на
   MarketGuru** — у него нет ни Ozon-аналитики топ-карточек, ни API, ни выгрузки фото.
   Ставить playbook по WB-данным нельзя: приоритетная площадка по `mvp_scope.yaml` — Ozon.
2. **MarketGuru был бы пригоден только в WB-сценарии** (если бы приоритет сменился на
   WB): там есть UI-просмотр фото и Excel-выгрузка таблиц, но по-прежнему без API и без
   пакетной выгрузки медиа — для golden set исходники фото пришлось бы качать вручную.
3. **Рекомендация — MPStats.** Публичный REST API (`https://mpstats.io/api/`,
   документация `https://mpstats.io/integrations/docs/description/`, авторизация
   `X-Mpstats-TOKEN`, JSON), покрытие Ozon. Дороже MarketGuru (от 10 392 ₽/мес против
   4 990 ₽/мес) — разницу в цене закрывает принципиальное наличие API и Ozon.
4. **Решение — за Денисом** (покупка, доступы). Обновление
   `configs/mvp_scope.yaml → q7_data_source` выполняется после решения, в рамках TEC-36.
