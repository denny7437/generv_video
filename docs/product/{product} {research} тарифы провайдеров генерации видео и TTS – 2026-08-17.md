# Тарифы провайдеров генерации видео и TTS — 2026-08-17

**Задача:** TEC-20 · **Владелец:** A-20 (hermes-product) · **Тип:** research (цены и условия)
**Основа:** пояснительная записка v1.1 §3.2/§3.5 и Приложение Б, дополнено проверкой лицензий весов по HuggingFace API.
**Назначение:** вход для юнит-экономики и для выбора провайдера (само решение — отдельный ADR, не здесь).

> Дисциплина источника: **уровень 1** — официальный прайс провайдера; **уровень 2** — официальная справка/скриншот кабинета; **уровень 3** — блог/обзор/рынок; **оценка** — диапазон без прямого источника. Числа из ПЗ v1.1 помечены `ПЗ §3.2` — они были проверены по открытым источникам 17.08.2026 и перепроверяются перед любым финансовым решением (правило маршрута «изменение стоимости»: A-20 → человек → cost_targets.yaml).

## 1. Резюме

- Бюджетный контур (цель ≤ $0,045/сек за вызов) реален: подтверждены модели в диапазоне $0,021–0,082/сек. Средневзвешенные $0,03/сек достижимы миксом, но **не** потолком на каждый вызов — под него проходит мало моделей, что ломает требование `min_budget_providers: 2`.
- Премиум-контур (цель ≤ $0,20/сек) определён Veo 3.1 ($0,20/сек без звука) и Kling v3 Pro ($0,112–0,196/сек). Sora 2 / Sora 2 Pro — запрещены (API отключается 24.09.2026).
- Локальные модели: коммерчески чистые веса (Apache-2.0/MIT) — Wan 2.1/2.2, Mochi 1, LTX-Video (до $10M выручки), HunyuanVideo (до 100M MAU, вне ЕС/UK/Корея), CogVideoX (нужна регистрация), Kokoro/Piper (TTS). **Нельзя брать:** XTTS-v2 (CPML, non-commercial), Fish Speech 1.5 (CC-BY-NC-SA).
- Self-host экономически не подтверждён авансом: дистиллированные модели на дешёвых картах дают лишь ~1,4–2,5× против API при хорошей утилизации, а Wan 2.2 A14B требует 48–80 ГБ VRAM и на 24 ГБ карты не влезает.

## 5. TTS-провайдеры (фаза 3, вне MVP)

> Озвучка в MVP исключена решением владельца (граница MVP, TEC-23). Тарифы TTS нужны только для планирования фазы 3.
>
> **Статус: не собрано.** Официальные страницы тарифов (ElevenLabs, OpenAI TTS, Google Cloud TTS, Azure Speech, Amazon Polly) в этой среде недоступны: терминал не имеет доступа к доменам прайсов, а делегированные субагенты получают только kanban-инструменты без web/shell. Выдумывать цены запрещено. Тарифы TTS собираются отдельным прогоном с web-доступом либо вручную Денисом при переходе к фазе 3.
>
> Что известно на сейчас: для self-host TTS коммерчески пригодны Kokoro-82M (Apache-2.0) и Piper (MIT); XTTS-v2 и Fish Speech — non-commercial (см. §3.1).

## 6. Чего выяснить не удалось

| Вопрос | Что пробовал | Кто может ответить |
|---|---|---|
| Точные лимиты стартового тарифа каждого API-провайдера (квоты, лимиты на секунды/генерации) | В ПЗ §3.2 даны только цены за секунду; страницы тарифов в этой среде недоступны (guard не пускает на домены прайсов) | Денис (вручную из кабинетов) или запуск с web-доступом |
| Разбивка «что входит в единицу» (разрешение/fps/длительность) для Kling, Hailuo, Wan 2.6 Flash | ПЗ не детализирует; требуется официальная страница модели | повторная проверка по прайсу |
| Точная цена Runway API (в кредитах) | прайс в кредитах без явного $ за единицу | docs.dev.runwayml.com |
| Цены TTS-провайдеров (ElevenLabs, OpenAI, Google, Azure, Polly) | домены прайсов недоступны; субагенты получили только kanban-инструменты без web | Денис (вручную) или запуск с web-доступом; нужен только для фазы 3 |

## 7. Что это значит для продукта

1. **Бюджетный потолок $0,045/сек на один вызов не оставляет запаса на резервирование.** Под него проходят Veo 3.1 Lite и низ ценового диапазона Wan. Kling v2.5 Turbo ($0,062) и Hailuo 2.3 ($0,082) — вне потолка одиночного вызова, но могут участвовать в средневзвешенном $0,03/сек. Формулировка «weighted vs single» в cost_targets.yaml это уже учитывает — менять ничего не нужно.
2. **Премиум-контур живёт на Veo 3.1 и Kling v3 Pro.** Оба в пределах $0,20/сек. Sora 2 ушёл из пула (24.09.2026) — премиум не зависит от одного поставщика.
3. **Self-host — гейт, не обещание.** Авансом экономию закладывать нельзя: только дистиллированные модели на дешёвых картах дают ≥ порога, и то по верхней границе замеров. Wan 2.2 A14B (лучшее качество среди открытых) на дешёвые 24 ГБ карты не встаёт.
4. **Для TTS (фаза 3) коммерческий путь — Kokoro-82M (Apache-2.0) или Piper (MIT) self-host, либо API-провайдеры.** XTTS-v2 и Fish Speech в контур не берём из-за non-commercial лицензий весов.
5. **Следующий шаг:** закрыть пустые ячейки «лимиты стартового тарифа» и TTS-секцию, затем — ADR по выбору провайдера бюджетного контура (Veo 3.1 Lite + Wan как минимум два поставщика).
