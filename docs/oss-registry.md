# Реестр open source

Единственный ответ на вопрос «что чужого у нас внутри и на каких условиях». Синхронность реестра с кодом проверяется в CI: `pnpm check:oss` падает, если в рабочих пространствах есть production-зависимость, которой нет в этой таблице.

Правила ведения — скилл `hermes-oss-scout`. Строка добавляется **в том же PR**, где появляется зависимость.

## Что ещё предстоит выбрать

Пустые строки — это не «забыли», а честная карта нерешённого. Каждая закрывается задачей с нулевой фазой OSS-разведки:

- клиент очередей (BullMQ) и UI наблюдаемости за ними;
- S3-клиент;
- провайдер генерации видео (коммерческий API и/или локальная модель);
- TTS для озвучки;
- фронтенд-стек и компонентная база;
- Playwright и оснастка e2e;
- миграционный инструмент.
