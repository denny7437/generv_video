# Контракт адаптера видео-провайдера

Провайдер генерации — за одним интерфейсом. Провайдер-специфика не покидает `services/worker-render`: ни в домене, ни в API, ни во фронтенде не должно быть слова «Kling», «Runway» или «ComfyUI».

Причина: в этой нише провайдеры меняются чаще, чем релизы продукта. Смена провайдера обязана быть заменой одного файла адаптера, а не рефакторингом трёх сервисов.

## Интерфейс

```ts
export interface GenerateRequest {
  scene: Scene;             // сцена из брифа
  preset: Preset;           // целевые размер, fps, длительность
  promptId: string;         // ссылка в реестр промптов
  timeoutMs: number;        // обязателен
}

export interface GenerateResult {
  clipRef: string;          // ключ S3 готового клипа
  durationMs: number;
  costMinor: number;        // фактическая стоимость, копейки
  providerJobId: string;    // для расследований на стороне провайдера
}

export interface VideoProvider {
  readonly name: string;
  /** Оценка ДО вызова: вход budget-guard. */
  estimateCost(request: GenerateRequest): Money;
  generate(request: GenerateRequest): Promise<GenerateResult>;
}
```

## Обязательные свойства реализации

| Свойство | Требование |
|---|---|
| Таймаут | задаётся вызывающим, не берётся из «дефолта библиотеки» |
| Параллелизм | ограничен на уровне очереди, а не внутри адаптера |
| Оценка стоимости | считается до вызова и проходит через `budget-guard` |
| Ошибки | маппятся в наши коды: `provider_timeout`, `provider_rate_limited`, `provider_rejected_content`, `provider_unavailable` |
| Ретраи | только технические (сеть, 5xx, rate limit); не увеличивают счётчик платных попыток |
| Ключи | только через переменные окружения; в логи, ошибки и отчёты значения не попадают |
| Мок | обязателен: `VIDEO_PROVIDER=mock`. Тесты и CI ходят только в него |

## Мок-провайдер

Мок — часть контракта, а не «времянка для тестов». Он обязан:

- возвращать клип нужной длительности и размера (генерируется ffmpeg `testsrc`);
- уметь имитировать сбой (`MOCK_FAIL_RATE`), таймаут и rate limit — иначе ветки обработки ошибок никогда не проверяются;
- считать стоимость по тем же правилам, что и боевой адаптер.

## Лицензионное предупреждение

Для локальных моделей проверяются **две** лицензии: код и веса. У генеративных видео-моделей условия на веса регулярно запрещают коммерческое использование, а продукт коммерческий. Решение по такой модели принимает человек — агент эскалирует (скилл `hermes-oss-scout`).
